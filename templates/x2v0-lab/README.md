# x2v0 Lab (Android App)

Интерактивная песочница (190 КБ). Демонстрирует 8 способов загрузки данных в WebView.

## 🔬 8 методов
1.  **Fetch API** (Блокируется CORS).
2.  **XHR** (Работает).
3.  **Script Tag** (Работает, JSONP).
4.  **LocalStorage** (Работает, кэш).
5.  **Iframe (srcdoc)** (Работает).
6.  **Base64 Data URI** (Работает).
7.  **Blob URL (Fake URL)** (Обход CORS).
8.  **Data URI (Fake URL)** (Обход CORS).

## 🚀 Особенности
*   **Размер**: ~190 КБ.
*   **Ноль прав**: Без интернета, всё офлайн.
*   **Встроенное Резюме**: Через меню.

## 🛠 Сборка
```bash
make base64   # Обновить en_base64.js
make build    # Сборка APK
make rebuild  # Очистка + Сборка
```
