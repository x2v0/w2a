# x2v0 Resume (Android App)

Ультра-легкое (98 КБ), полностью офлайн-приложение-визитка, собранное с помощью `wta`.

## 🚀 Особенности
*   **Размер**: ~98 КБ.
*   **Офлайн**: 100% автономность. Контент внутри APK.
*   **Ноль прав**: В манифесте нет ни единого разрешения.
*   **Шрифты**: Системные (Roboto), без загрузки из сети.
*   **Нативный PDF**: Кнопка вызывает системное окно печати Android.

## 🛠 Сборка
```bash
make build    # Сборка APK
make rebuild  # Очистка + Сборка
make help     # Справка
```
