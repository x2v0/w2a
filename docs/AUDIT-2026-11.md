# Аудит телефона: 65 приложений с нативными мостами (ноябрь 2026)

## Что делали
Через Shizuku вытащили ~100 APK, прогнали через `strings` + `baksmali`.
Нашли 65 приложений со строками `@JavascriptInterface`. Провели smali-разбор ключевых.

## Ключевые находки

### x2v0-lab (наш)
- Мосты: AndroidShellBridge, AndroidFileBridge, AndroidSystemBridge, AndroidFilesBridge, AndroidClipBridge, AndroidIntentBridge
- Умеет: Runtime.exec, readFile, getClipboard, sendIntent
- Вердикт: **ожидаемо** (мы сами это писали для Лаборатории)

### DeepSeek
- Мосты: JSBridge
- Методы: exportPngBase64, requestRenderMermaid
- Вердикт: **безопасно** (только рендер картинок)

### MAX (ru.oneme.app)
- Мосты: WebViewHandler (zti), AndroidPerf (ami), PrivateWebViewHandler (ouc)
- Методы: postEvent, resolveShare, getUserInfo
- Защита: FileProvider, санитайзер q11.b(), FLAG_GRANT_READ_URI_PERMISSION
- Вердикт: **безопасно** (учебник по безопасности)

## Паттерны для w2a
1. FileProvider вместо file://
2. Санитайзер имён файлов (см. q11.b в MAX)
3. FLAG_GRANT_READ_URI_PERMISSION при ACTION_SEND
